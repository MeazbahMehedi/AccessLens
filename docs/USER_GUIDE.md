# User guide

1. Start AccessCheck and open `http://127.0.0.1:8000`.
2. Enter a complete public `https://` or `http://` URL and choose a WCAG target level.
3. Wait for the scan to complete. A results page shows the score, severity counts, principle scores, screenshot, and findings.
4. For each finding, inspect the selector, sample HTML, WCAG criteria and fix suggestion.
5. Download JSON for machine-readable results, CSV for spreadsheet work, or PDF for sharing.
6. Open History to revisit recent scans.

Scores are heuristic indicators based on the weighted findings returned by checks. Review issues manually and test with keyboard navigation and assistive technologies.
