# Future work

These capabilities are not part of the current release:

- Authenticated team workspaces and ownership of scan records.
- Multi-page crawling with per-page scope and controlled resource budgets.
- A durable external job queue and distributed workers.
- Same-page/same-target scan comparisons and regression detection.
- Keyboard-flow and assistive-technology evaluation workflows.
- Database migrations beyond the supported SQLite additive upgrade.
- Retention controls, stronger browser sandboxing and enforced egress policy.
- Scheduled scans and notifications.
- Broader operating-system and mobile-browser validation.
- Tagged PDF/accessible document output and improved complex-script font support.

Contributions should preserve the distinction between confirmed automated failures, manual-review items and recommendations.
